# Gemini CLI Project Instructions

@./AGENTS.md
@./AGENTS_LOG.md

`AGENTS.md` is the canonical engineering contract.
`AGENTS_LOG.md` is the shared multi-agent execution ledger.

Before every non-trivial task:
1. Read both files.
2. Inspect Git/repository state.
3. Check active task claims and file ownership.
4. Claim the task before editing.
5. Record verification before completion.
6. Leave a handoff when another agent may continue.

Repository state, tests, and evidence outrank model assumptions.
