# BilsenBol — персональный маршрут поступления

> **Демо:** ⚠ ЗАПОЛНИТЬ — ссылка на развёрнутый сайт
> **Кейс:** LOCUS Startup Hackathon 2026, кейс 02 «Персональный маршрут поступления» (`LOCUSCASE2`)

BilsenBol превращает профиль школьника в понятный маршрут поступления: куда
подаваться, почему именно туда и что сделать на этой неделе.

## Запуск

```bash
npm install
npm run dev          # http://localhost:3000
```

Регистрация не нужна. Проверки и продакшен-сборка:

```bash
npm run typecheck && npm run lint && npm run build && npm start
```

**ИИ-план (необязательно).** Скопируйте `.env.example` в `.env.local` и укажите
`GEMINI_API_KEY` и/или `GROQ_API_KEY`. Без ключей всё работает, только без
советов ИИ. На Vercel те же переменные задаются в настройках проекта.

С телефона в той же сети откройте адрес из вывода `next dev`
(`http://192.168.x.y:3000`).

## Задача

Поступление — это десятки решений: направление, страна, вуз, экзамены,
документы, сроки. Информация разрознена, поэтому абитуриент не понимает, что
подходит именно ему и что делать сейчас.

**Аудитория:** школьники 9–11 классов и выпускники из стран СНГ, поступающие на
бакалавриат, в том числе за рубеж.

## Решение

| Этап кейса | В BilsenBol |
|---|---|
| Вход | Лендинг, кнопка «Начать», три пресета в один клик |
| Профиль | Анкета из 6 вопросов: класс, балл, английский, бюджет, интересы, регионы |
| Диагностика | Статус готовности, 4 шкалы (балл, язык, бюджет, подборка), сильная сторона и узкое место |
| Рекомендации | Реальные программы, прошедшие обязательные условия: оценка совпадения, цена, английский, ближайший срок, источник; в «Подробнее» — причины, компромисс, как усилить заявку |
| Сравнение | Две программы по 10 критериям, лучшее значение отмечено |
| Roadmap | План по сезонам с иконками шагов, кольцо прогресса. При 100% открывается ИИ-план: кликабельное древо маршрута, советы ИИ к каждому узлу, экспорт чек-листа в PDF |
| Следующее действие | Карточка «Следующий шаг» с кнопкой «Выполнено»; колокольчик с напоминаниями о дедлайнах и шагах, экспорт дедлайна в календарь (`.ics`) |

**Требования к UX/UI:**
- **Навигация:** степпер из 4 шагов и счётчик «N / 6» в анкете.
- **Объяснения:** у каждой рекомендации есть объяснение и разбивка оценки по факторам.
- **Дизайн-система:** единая система на CSS-токенах.
- **Мобильная версия:** проверена на 330–390 px.
- **Реакция на изменения:** плашка «Что изменилось» после каждой правки условий.
- **Источники:** ссылки на официальные источники на каждой карточке.

## Тестовый сценарий

1. На главной нажмите «Начать», ответьте на 6 вопросов → «Построить мой маршрут».
2. **Разбор:** статус, шкалы готовности, сильная сторона и узкое место.
3. **Подбор:** карточки с ценой, английским и сроком; раскройте «Подробнее».
4. **Сравнение:** «Сравнить» на двух карточках, затем на нижней панели.
5. **Реакция:** «Ваши условия → Изменить», смените бюджет или регион. Для IT-пресета бюджет «До $3 000» даёт «Программ: 6 → 4».
6. **План:** «Выполнено» двигает кольцо прогресса; после перезагрузки прогресс на месте. Колокольчик в шапке показывает напоминания.
7. **ИИ-план** (нужен ключ): закройте все шаги → «Открыть ИИ-план». Нажмите на узел древа, затем «Чек-лист в PDF».
8. **Пустое состояние:** в IT-пресете выберите английский «Только школьный», бюджет «$0» и из регионов только «США» → «Ничего не подошло» с причинами отсева и кнопкой смягчения.
9. **Пресеты** на главной и мобильная ширина 330–390 px.

## Архитектура

Модульный монолит: бизнес-правила — чистые функции, отдельно от интерфейса.

```text
src/
  app/         маршруты: /, /journey, /journey/ai, /api/roadmap
  domain/      profile, matching, diagnosis, roadmap, comparison, reminders
  data/        programs.ts — каталог реальных программ с источниками
  features/    экраны: profile, diagnosis, recommendations, comparison,
               roadmap, progress, reminders, journey
  server/ai/   только сервер: промпт, адаптеры Gemini и Groq, цепочка
  components/, lib/   общие компоненты и утилиты
```

**Поток данных.** Единственный источник состояния — профиль. Разбор, подборка,
план и напоминания заново вычисляются из него, поэтому правка сразу видна
везде. Профиль и прогресс хранятся в `localStorage` (с проверкой при чтении),
базы данных нет.

**Логика подбора — прозрачные правила.**
1. **Жёсткие ограничения** отсекают программу, если выполнено любое из условий:
   - регион не выбран;
   - цена выше бюджета и нет полной стипендии. Цена пересчитывается в USD по официальному курсу;
   - ваш сертификат не принимают, и нет обходного пути: экзамена вуза или подготовительной программы.

   Средний балл не фильтрует: вузы не публикуют порог по шкале СНГ.
2. **Мягкие факторы** дают оценку совпадения 0–100:
   - направление: 34;
   - бюджет или стипендия: 4–18;
   - английский: 8–14;
   - балл для стипендий: 8–14;
   - регион: 8;
   - обязательные условия: 6;
   - без подготовительного года: 6.

   Это совпадение с профилем, **не вероятность поступления**.
3. **Объяснение** каждой карточки собирается из тех же факторов.

**ИИ-план.** Скелет плана всегда строится правилами, ИИ только дополняет его.
1. Сервер строит план сам из проверенного профиля и передаёт модели анкету
   словами, без чисел.
2. Модель отвечает JSON по схеме: стратегия, совет к каждому шагу, до 3 доп.
   шагов.
3. Код отбрасывает чужие id шагов, слишком длинные тексты, ссылки и **любые
   цифры**. Так выдуманные даты, цены и шансы не попадают на экран.
4. Если Gemini недоступен, запрос уходит в Groq с той же проверкой, общий
   дедлайн 26 с. Если не ответили оба, страница честно пишет «ИИ недоступен».
5. Кэш на сервере и в браузере; не больше 20 вызовов в минуту.

## ИИ и API

- **Подбор, разбор и план** — правила (rule-based), модель в них не участвует.
- **Gemini API**, эндпоинт `generateContent`, без хранения истории: `gemini-3.5-flash-lite`, запасная `gemini-3.1-flash-lite`.
- **Groq API**, эндпоинт `chat/completions`, строгая JSON-схема: `openai/gpt-oss-120b`, запасная `openai/gpt-oss-20b`.
- Модели выбраны по замерам на бесплатном тарифе.
- **В модель уходят** только анонимные поля анкеты словами и названия программ. Личные данные не собираются.
- **Ключи** хранятся только в переменных окружения сервера.
- При разработке команда использовала ИИ-ассистентов для кода. Правила работы описаны в `AGENTS.md`, журнал ведётся в `AGENTS_CHANGELOG.md`.

## Ограничения

- Каталог небольшой (15 программ), проверен вручную на 19.09.2026. Цены и даты меняются, поэтому на карточках есть дата проверки и источники.
- Часть окон подачи относится к набору 2026: даты 2027 ещё не опубликованы.
- Из экзаменов фильтрует только английский. ЕНТ, SAT и другие экзамены показаны как вступительные испытания.
- Регионы, а не страны. Сравниваются ровно две программы.
- Прогресс хранится в браузере, без аккаунтов и синхронизации.
- Напоминания видны на сайте. Чтобы получать их при закрытом сайте, добавьте дедлайн в календарь (`.ics`).
- PDF сохраняется через печать браузера: кнопка «Сохранить как PDF».
- ИИ-советы проверяются на форму и цифры, но не на смысл. Поэтому они подписаны как советы, а не требования.
- Бесплатные квоты ИИ ограничены: один план — около 2 100 токенов, на Groq это около 85 планов в день на модель.
- Автотестов в репозитории пока нет (см. «Методы проверки»).

**Методы проверки.**
- `typecheck`, `lint`, `build` проходят без ошибок.
- **Доменные прогоны:**
  - у каждого пресета не меньше 3 программ;
  - жёсткие ограничения не нарушаются;
  - смена условий меняет результат;
  - прогресс считается верно;
  - напоминания проверены на фиксированных датах.
- **Headless Chrome с касаниями на 330/360/390 px:**
  - нажатия;
  - сохранение и повреждённое хранилище;
  - «Что изменилось»;
  - древо и меню узлов;
  - PDF;
  - колокольчик и `.ics`;
  - отсутствие горизонтальной прокрутки.
- **ИИ:**
  - живые запросы к Gemini и Groq; фильтр не пропустил ни одной цифры;
  - фолбек, таймауты и квоты — на подменённом `fetch`.
- Эти прогоны выполнялись при разработке и не входят в репозиторий. Следующий шаг — перенести их в Vitest и Playwright.
